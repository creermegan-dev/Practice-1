# Campus Store POS Kiosk

A touchscreen-friendly Point of Sale kiosk created for the IT415 Practical Examination.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Storage

The application uses browser-based JavaScript storage for transaction data.
No external database is required.

## Main Features

- Product selection
- Cart management
- Quantity increase and decrease
- Remove items
- Automatic subtotal and total calculation
- Order Summary
- Cash payment
- QR payment simulation
- Credit/Debit Card payment simulation
- Cash payment validation
- Automatic change calculation
- Payment Successful screen
- Unique transaction reference
- Digital receipt
- New Transaction reset
- Transaction History

## How to Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. The POS application will open in the browser.

The project was developed using Git and GitHub with feature branches, commits, pull requests, reviews, and merges.
